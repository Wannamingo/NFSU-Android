# Компоненты предварительной версии

Этот репозиторий содержит выпуски приложения и пользовательскую документацию. Он пока не является полным набором исходников для воспроизводимой сборки APK. Обычные архивы GitHub «Source code» содержат дерево этого репозитория, а не исходники всех встроенных библиотек и не игровые данные.

Выпуск меняет Java/DEX экранного управления и подсказки лаунчера. Все нативные библиотеки, драйверы, звук, русификация и игровые дополнения побайтно сохранены из preview.5. Поэтому исправление дрэга и режим 20:9 остаются в том же нативном коде. Публичный APK побайтно сохраняет DEX/native/драйверы/assets принятого пользователем Huawei APK `1c698434`; отличаются только AndroidManifest и HTML-строка версии. Сам публичный APK отдельно на телефоне не запускался.

Приёмка: пользователь подтвердил работу V2 на Huawei; пройдены 3205 проверок руления и 2170 проверок общей паузы, прежние тесты неонового оформления и размера. Они проверяют логику ввода и раскладки, но не являются новой GPU-матрицей, сравнением FPS или проверкой всех устройств Mali/Adreno. На RG477M новое UI в этом этапе не проверялось. Выбор руления хранится отдельно от позиций и физических назначений; при установке принятого Huawei APK UID, настройки и render были сохранены без очистки данных.

Исторические проверки сохраняют свою область: drag-fix в preview.5 прошёл 115 host и 115 Huawei ARM64 проверок и подтверждён в дрэге. Для T30 в preview.4 проверялись два холодных запуска, изображение гонки и возврат к System Vulkan на Huawei HWMNA. Старый полный GLES/ANGLE GPU-тест на этом Huawei не создал EGL с обоими драйверами; успешный прогон ему не приписывается.

В релиз приложен новый архив исходников UI, а также сохранён небольшой исходный patch дрэга. Пакеты содержат только соответствующие исходники интеграции; это не полный набор для сборки игрового libmain.so. Исходники исправленного custom-loader и его зависимости AdrenoTools также предоставляются отдельно. Обычные архивы GitHub Source code содержат документацию этого репозитория.

## Основные зависимости

- [Purple Turnip T30, MrPurple666](https://github.com/MrPurple666/purple-turnip/releases/tag/vturnip_mrpurple_T30-toasted.adpkg): неизменённый авторский ZIP `turnip_mrpurple_T30-toasted.adpkg.zip`, metadata version `26.3.0-T30-1.4.359`, minApi 30. Встроенный экспериментальный вариант для подходящих Adreno. [Уведомление о пакете](../licenses/Purple-Turnip-T30-NOTICE.txt).

- [MaliSX2](https://github.com/bmdhacks/malisx2/tree/090e0c43a174a95284782f6129ee7de250256e3d), с локальными изменениями. SHA-256 встроенного драйвера: `577a7ea21a54e8f107e296abb00eee7b8e6b0e6db1b9d39aa6fb89427228a455`.
- [Mesa, используемая ветвь](https://github.com/bmdhacks/armsx2-turnip/tree/730a6284cb7a88f6c19a07f1caea35c7a2ae64f2). Лицензии отдельных компонентов сохраняют самостоятельное действие.
- [AdrenoTools / linkernsbypass в ARMSX2](https://github.com/ARMSX2/ARMSX2/tree/a8031268e53ed9576c6093913671d4628210fd97), BSD-2-Clause. Импорт пользовательского драйвера действует внутри приложения.
- [xboxrecomp](https://github.com/sp00nznet/xboxrecomp/tree/74649ef5b0f023e7b878043bc6de2534c55e717e), с локальными изменениями системного слоя. Его MIT-лицензия не заменяет отдельные условия файлов, перечисленных в upstream NOTICE.
- [SDL](https://github.com/libsdl-org/SDL/tree/fa2c02bb6e21974a89ea9824bc53c9932abe5f9c): описание использованного Android AAR указывает 3.4.16 и этот commit.
- glslang и SPIRV-Cross: статические библиотеки преобразования шейдеров. Лицензионные тексты включены; точные upstream commits использованных готовых архивов ещё не установлены.
- LLVM C++ runtime и xxHash: уведомления включены в каталог лицензий.
- ANGLE: совместимые библиотеки получены из прошивки RG477M, GLES-библиотека содержит локальные строковые изменения. Для них не заявляется сборка из установленной точной upstream-ревизии; приложенный upstream LICENSE обозначен как справочный.

Оригинальные тексты условий и уведомлений находятся в [licenses](../licenses/README.md). Общая ссылка на upstream не означает, что его текущая версия побайтно совпадает с локально изменённой библиотекой.
