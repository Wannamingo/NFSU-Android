# NFSU Android

Предварительная версия нативного Android-порта Need for Speed Underground для ARM64 на основе статической рекомпиляции Xbox-версии.

**[Подробное руководство: управление, настройки, сохранения и перенос прогресса](docs/GUIDE-RU.md)**

## Возможности

- Самостоятельный Vulkan-рендерер, отдельный поток подготовки графики, арены геометрии и подготовленные ключи состояний.
- Системный Vulkan, выбор встроенного MaliSX2 и импорт совместимого пользовательского драйвера из ZIP.
- Полная экранная раскладка и отдельные кнопки вождения, перетаскивание элементов и размер гоночных кнопок 40–100%.
- Геймпады, отдельные назначения экранных и физических кнопок, перестановка A/B и X/Y.
- Форматы изображения 4:3 и 16:9, внутренний масштаб 1×/2×/3×, предел 60 или 120 FPS.
- Русский и английский интерфейсы.
- Автоматические копии игровых профилей в `Download/NFSU/Saves`, хранение последних 10 собственных поколений и восстановление через системный выбор папки.
- Ускоренное точное преобразование swizzled-текстур и переиспользование Vulkan pipeline cache на системном драйвере. Проверки изменений текстур сохранены.

## Статус версии

Кандидат первой публичной версии — **0.2.0-preview.1**, versionCode 3, APK `be140f7c`. В нём побайтно сохранены нативный код, драйверы и русификация проверенной общей сборки `c8fcc955`. Добавлены быстрые начальные настройки для чистой установки, исправлены подписи разрешений, добавлены уведомления о сторонних компонентах и выключен отладочный режим. Подпись совместима с предыдущими тестовыми APK. Сам кандидат ещё ожидает отдельной проверки запуска на устройстве.

На исходной c8 на RG477M выполнены 54 группы графических проверок и отдельные проверки обоих доступных Vulkan-путей. На Huawei MNA-LX9 с Adreno 730 проверен системный Vulkan; Mali-ориентированная матрица из 54 групп на нём не запускалась. Точные проверки преобразования текстур и сценарий переноса профиля между устройствами пройдены. Для нового инициализатора выполнены 10 проверок на компьютере, весь Android-код компилируется. Полного сопоставимого замера гонки на окончательном APK ещё нет; стабильные 60/120 FPS и отсутствие всех просадок не заявляются.

Репозиторий и руководство подготавливаются к первому выпуску. Ссылка на скачивание появится после завершения приёмки кандидата и публикации GitHub Release. В новом APK отключён debuggable; закрытый ключ подписи в публичную поставку не входит. Совместимость со всеми Mali и Adreno не заявляется.

## Игровые данные

Для запуска нужен собственный совместимый образ **NFS Underground для оригинальной Xbox, USA**. Игра импортируется через лаунчер из ISO или ZIP. PC-версия и Underground 2 не подходят. Образ игры, сохранения пользователей и личные журналы не поставляются в репозитории.
